### 根据鉴权信息直接获取用户信息

> BASIC

**Path:** /open/oidc/userInfoByAuth

**Method:** GET

**Desc:**

根据鉴权信息直接获取用户信息


> REQUEST

**Query:**

| name | value | required | desc |
| ------------ | ------------ | ------------ | ------------ |
| ed |  | NO |  |
| sh |  | NO |  |
| sg |  | NO |  |
| tm |  | NO |  |
| isSaas |  | NO |  |
